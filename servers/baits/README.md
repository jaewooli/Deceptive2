# baits — 미끼 정의 (함정 T1~T7)

미끼마다 위치·내용 템플릿·고유 ID·가리키는 목적지를 코드로 정의하고, SSM Run Command 또는 Ansible로 배포·교체·회수한다(변경 C).

- **실제 값은 커밋하지 않는다.** 템플릿에는 `{{ 자리표시자 }}`만 두고 배포 시 주입 (`.gitleaks.toml` 허용 목록)
- 일정: 11/25(T1~T5, Ansible 배포 경로 상한 2시간, 로컬), 11/26(T6 흔적, 로컬), 11/28(T6 IAM 키·SSM 배포 전환, AWS), 12/2 저녁(T7, 여유 시)
