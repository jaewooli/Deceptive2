# 채용 공고 요구사항 ↔ 프로젝트 스펙 대응표

작성: 2026-11-19

## 1. 목표 직무
**원청(일반 기업 내부 보안팀)의 보안 엔지니어 — 클라우드 탐지 엔지니어링(Detection Engineering)**
- 보안관제(모니터링 교대 운영)가 아니라, 위협 시나리오 정의 → 로그 수집 → 탐지 룰 설계·튜닝 → 대응 자동화를 만드는 역할
- 아래 공고는 대부분 경력직이다. 신입 지원 시 "이 역량을 프로젝트로 증명했다"는 근거로 쓴다.

## 4. 이 대응표가 바꾼 설계
- 행위자 묶기를 HASSH 기준에서 **침투 체인 상관분석**으로 교체 — 공고 A의 "상관분석·탐지 룰", 실제 OS 디코이에서 수집 가능한 데이터로 구현 가능
- 오탐 기준을 "0건"에서 **오탐 튜닝 과정**으로 교체 — 공고 A의 "오탐을 줄이는 탐지 품질 개선"
- 룰·검증 세트를 코드로 관리하고 회귀 테스트 — 공고 B의 Detection-as-Code
- 보고서는 공고 A의 요구대로 사례 중심(목표 → 시도 → 막힌 점 → 검증 → 배운 점)
