# 공격자 시점 스모크(infra/checks/paths.py로 실행). 호스트 = 공격자가 서 있는 서버. 기대 = 진짜 이웃(db-backup-01 10.0.20.15)과 같은 값
# 서버에 파일을 남기지 않는다(tcpdump 출력은 표준출력으로)
# ---- L3: 중계된 디코이도 같은 서브넷 이웃처럼(TTL 64, MSS 1460, DF 1500 통과, traceroute 1홉) — 11/23 실측 단서
web-01 | has | ping -c1 -W2 10.0.20.15 | ttl=64 | 기준: 진짜 이웃 ICMP TTL 64
web-01 | has | ping -c1 -W2 10.0.20.30 | ttl=64 | 투영 stg-01 ICMP TTL 64
web-01 | has | ping -c1 -W2 -M do -s 1472 10.0.20.30 | 1480 bytes from 10\.0\.20\.30 | 투영: DF 1500바이트 통과(PMTU 블랙홀 없음)
web-01 | has | tracepath -n -m 3 10.0.20.30 | ^ 1:  10\.0\.20\.30 .*reached | 투영: traceroute 1홉에 도달
web-01 | has | timeout 5 tcpdump -c1 -nvi enp0s3 'src host 10.0.20.30 and src port 22 and tcp[13]&18==18' 2>/dev/null & sleep 1; timeout 2 bash -c 'exec 3<>/dev/tcp/10.0.20.30/22'; wait | ttl 64,[\s\S]*mss 1460 | 투영: SYN-ACK TTL 64·MSS 1460
web-01 | has | timeout 5 tcpdump -c1 -nvi enp0s3 'src host 10.0.20.10 and src port 6379 and tcp[13]&18==18' 2>/dev/null & sleep 1; timeout 2 bash -c 'exec 3<>/dev/tcp/10.0.20.10/6379'; wait | ttl 64,[\s\S]*mss 1460 | 트랩 app-01:6379 SYN-ACK = app-01:22와 같음
app-01 | has | timeout 5 tcpdump -c1 -nvi enp0s3 'src host 10.0.20.11 and src port 8080 and tcp[13]&18==18' 2>/dev/null & sleep 1; timeout 2 bash -c 'exec 3<>/dev/tcp/10.0.20.11/8080'; wait | ttl 64,[\s\S]*mss 1460 | 트랩 web-01:8080 SYN-ACK TTL 64·MSS 1460
# ---- 응용 계층
web-01 | has | timeout 15 ssh -o BatchMode=yes -o StrictHostKeyChecking=no -o UserKnownHostsFile=/dev/null 10.0.20.30 true 2>&1 | Permission denied \(publickey\) | 투영 SSH 키 교환 끝까지(인증 단계 도달)
web-01 | has | printf 'CLIENT LIST\r\nQUIT\r\n' > /dev/tcp/10.0.20.10/6379 2>&1; timeout 3 bash -c 'exec 3<>/dev/tcp/10.0.20.10/6379; printf "CLIENT LIST\r\n" >&3; timeout 1 cat <&3' | addr=10\.0\.20\.11:\d+ laddr=10\.0\.20\.10:6379 | 트랩 Redis CLIENT LIST: 진짜 출발지·EDH 주소
