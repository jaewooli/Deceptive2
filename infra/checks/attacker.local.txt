# 공격자 시점 스모크(infra/checks/paths.py로 실행). 호스트 = 공격자가 서 있는 서버. 기대 = 진짜 이웃과 같은 값
# 구간(11/23): pub 10.0.21.0/24 = web-01 .11, stg-01(투영) .12 / int 10.0.20.0/24 = app-01 .10, dev-01(투영) .11, db-backup-01 .15
# 서버에 파일을 남기지 않는다(tcpdump 출력은 표준출력으로)

# ---- L3, 같은 구간: 투영 디코이도 이웃처럼(TTL 64, MSS 1460, DF 1500 통과, traceroute 1홉) — 11/23 실측 단서
web-01 | has | ping -c1 -W2 10.0.21.12 | ttl=64 | stg-01(투영, 같은 구간) ICMP TTL 64
web-01 | has | ping -c1 -W2 -M do -s 1472 10.0.21.12 | 1480 bytes from 10\.0\.21\.12 | stg-01: DF 1500바이트 통과(PMTU 블랙홀 없음)
web-01 | has | tracepath -n -m 3 10.0.21.12 | ^ 1:  10\.0\.21\.12 .*reached | stg-01: traceroute 1홉에 도달
web-01 | has | timeout 5 tcpdump -c1 -nvi enp0s3 'src host 10.0.21.12 and src port 22 and tcp[13]&18==18' 2>/dev/null & sleep 1; timeout 2 bash -c 'exec 3<>/dev/tcp/10.0.21.12/22'; wait | ttl 64,[\s\S]*mss 1460 | stg-01: SYN-ACK TTL 64·MSS 1460
web-01 | has | ping -c1 -W2 10.0.21.12 >/dev/null; ip neigh show 10.0.21.12 | lladdr 52:54:00:21:00:30 | stg-01 ARP = 센서 pub NIC MAC(디코이 NIC MAC과 같아야 — 안쪽 검사에서)
# ---- L3, 다른 구간: VPC처럼 TTL이 안 줄고 1홉(로컬 라우터 보정)
web-01 | has | ping -c1 -W2 10.0.20.15 | ttl=64 | 기준: 다른 구간 진짜 서버 TTL 64
web-01 | has | tracepath -n -m 3 10.0.20.15 | ^ 1:  10\.0\.20\.15 .*reached | 기준: 다른 구간도 traceroute 1홉
app-01 | has | ping -c1 -W2 10.0.21.12 | ttl=64 | stg-01(다른 구간에서) TTL 64
# ---- 트랩 중계: 넘긴 포트도 같은 서버의 다른 포트와 같게
web-01 | has | timeout 5 tcpdump -c1 -nvi enp0s3 'src host 10.0.20.10 and src port 6379 and tcp[13]&18==18' 2>/dev/null & sleep 1; timeout 2 bash -c 'exec 3<>/dev/tcp/10.0.20.10/6379'; wait | ttl 64,[\s\S]*mss 1460 | 트랩 app-01:6379 SYN-ACK = app-01:22와 같음
app-01 | has | timeout 5 tcpdump -c1 -nvi enp0s3 'src host 10.0.21.11 and src port 8080 and tcp[13]&18==18' 2>/dev/null & sleep 1; timeout 2 bash -c 'exec 3<>/dev/tcp/10.0.21.11/8080'; wait | ttl 64,[\s\S]*mss 1460 | 트랩 web-01:8080 SYN-ACK TTL 64·MSS 1460
# ---- 응용 계층
web-01 | has | timeout 15 ssh -o BatchMode=yes -o StrictHostKeyChecking=no -o UserKnownHostsFile=/dev/null 10.0.21.12 true 2>&1 | Permission denied \(publickey\) | stg-01 SSH 키 교환 끝까지(인증 단계 도달)
web-01 | has | timeout 5 curl -s -o /dev/null -w '%{http_code}' http://10.0.21.12/ | ^200$ | stg-01 웹(옛 스테이징 앱) 응답
web-01 | has | timeout 3 bash -c 'exec 3<>/dev/tcp/10.0.20.10/6379; printf "CLIENT LIST\r\n" >&3; timeout 1 cat <&3' | addr=10\.0\.21\.11:\d+ laddr=10\.0\.20\.10:6379 | 트랩 Redis CLIENT LIST: 진짜 출발지·EDH 주소
